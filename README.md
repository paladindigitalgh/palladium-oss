# Palladium OSS

Palladium OSS is a modern, vendor-neutral Operations Support System (OSS) designed for broadband providers, ISPs, municipalities, and fiber operators.

## Vision

Palladium manages inventory, customers, services, provisioning workflows, and network automation while integrating with specialized systems such as monitoring, ACS platforms, and billing systems.

## Status

🚧 Early development.

The architecture is being developed using an AI-assisted workflow with Claude Code and ChatGPT.
